# Parity

A crypto and currency converter written in C++.

- Fetches live crypto prices (CoinGecko) and forex rates (open.er-api.com)
- 30-second caching and concurrent fetching
- Input validation and 14 unit tests
- Dark web frontend in HTML, CSS and JavaScript

Built with C++, CMake, cpr, nlohmann/json and cpp-httplib.
